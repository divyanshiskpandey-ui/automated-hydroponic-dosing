# Automated Hydroponic Nutrient Dosing System

A PLC-controlled automated nutrient dosing system developed for a Nutrient Film Technique (NFT) hydroponic setup.

**Final Year Project — Automation & Mechatronic Systems, Ngee Ann Polytechnic**

## Overview

This project focused on enhancing an existing hydroponic control system by automating nutrient dosing for butterhead lettuce.

The system uses a PLC to control peristaltic pumps based on Electrical Conductivity (EC) requirements. The project also involved improving system monitoring through an OMRON HMI, implementing automated nutrient circulation, redesigning the sensor mount, and evaluating automated dosing against manual dosing through crop trials.

## My Contributions

- Designed and tested the automated nutrient dosing system
- Developed the dosing sequence using a Finite State Machine (FSM)
- Conducted pump repeatability and flow-rate testing
- Integrated peristaltic pumps with the PLC
- Enhanced the OMRON HMI with dosing status, pump status, and event logging
- Designed and tested an automated nutrient circulation system
- Designed and 3D printed components for the circulation system
- Redesigned and tested the sensor mount
- Conducted experimental comparisons between automated and manual dosing

## Key Results

- Measured a repeatable pump flow rate of **150 mL/min**
- Nutrient circulation reduced EC response time across all four tested reservoir locations
- Automated dosing produced higher average shoot weight and dry weight than manual dosing across both crop trials
